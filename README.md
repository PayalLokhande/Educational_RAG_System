# 🎓 PrepMate – AI Interview & Project Viva Simulator

## 📌 Project Overview

**PrepMate** is an AI-powered educational platform built using the **Retrieval-Augmented Generation (RAG)** approach to help students prepare for **Technical Interviews** and **Project Viva Examinations**.

The application personalizes interview and viva experiences by utilizing uploaded resumes and project reports as contextual knowledge. Through AI-generated questions, response evaluation, scoring, and personalized feedback, PrepMate provides an interactive learning environment that helps students improve their communication, technical understanding, and interview performance.

This project was developed as part of an internship under the **AI-Based Educational RAG System** theme.

# 🎯 Project Objective

The objective of PrepMate is to enhance students' preparation for technical interviews and project viva examinations by combining document retrieval with Large Language Models through a Retrieval-Augmented Generation (RAG) pipeline.

By leveraging uploaded resumes and project reports, the system generates personalized questions, evaluates responses, provides detailed feedback, and maintains session history for continuous learning and performance improvement.
